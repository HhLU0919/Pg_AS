# Pg_AS

This repository provides scripts and datasets supporting the analyses of alternative splicing and gene expression conducted in this study.

The repository is organized into the following directories:

# code

This directory contains a custom script for converting gene expression count data into FPKM (Fragments Per Kilobase of transcript per Million mapped reads) values.
The script uses gene count data generated by featureCounts as input and performs FPKM normalization based on gene length and sequencing depth.

# AS_events_and_DASG

This directory contains alternative splicing analysis results for three tissues:
brain
liver
muscle

For each tissue, analyses were conducted for the following pairwise comparisons:
AF – Active vs. Freezing
FR – Freezing vs. Recovery
AR – Active vs. Recovery

The directory includes:
Raw alternative splicing output files generated by rMATS-turbo
Tables containing the numerical results used to identify differentially alternatively spliced genes (DASGs) according to the filtering criteria described in the manuscript.

# GO_enrichment

This directory contains Gene Ontology (GO) enrichment analysis results for differentially alternatively spliced genes (DASGs) and differentially expressed genes (DEGs) in the three tissues (brain, liver, and muscle) across the same three comparisons (AF, FR, and AR).
For each tissue, GO enrichment analyses were performed separately for DASGs and DEGs.

Files named p_merge_*_GO.csv represent merged GO enrichment tables.
In these files, all GO terms identified in either DASG or DEG enrichment analyses are combined into a single table for the corresponding tissue.
For each GO term:

If the term is present in a given enrichment result, the associated p-value is reported.
If the term is absent from that analysis, the value is recorded as NA.

These merged tables facilitate comparison of GO enrichment patterns between DASGs and DEGs within each tissue.
