# Pg_AS
Repository Overview

This repository contains scripts and datasets supporting the analyses presented in our study on alternative splicing and cold adaptation.

# code

This folder contains a custom script developed for the conversion of gene expression counts to FPKM values.
The script takes the output files generated by featureCounts as input and calculates FPKM values for downstream analyses.
This script was provided in response to reviewers’ requests for the detailed implementation of the FPKM calculation procedure.

# AS_events_and_DASG

This folder contains alternative splicing analysis results for three tissues: brain, liver, and muscle.
For each tissue, results are provided for three pairwise comparisons:
AF: Active vs. Freezing
FR: Freezing vs. Recovery
AR: Active vs. Recovery

The folder includes:
Raw output files generated by rMATS-turbo.
Tables containing the numerical results used for identifying differentially alternatively spliced genes (DASGs) according to the filtering criteria described in the manuscript.

# GO_enrichment

This folder contains Gene Ontology (GO) enrichment analysis results for both DASGs and differentially expressed genes (DEGs) in the three tissues (brain, liver, and muscle) across the same three comparisons (AF, FR, and AR).
For each tissue, GO enrichment results were generated separately for DASGs and DEGs.

Files named p_merge_*_GO.csv represent merged GO result tables.
In these files, all GO terms identified in either DASG or DEG enrichment analyses are combined into a single table for the corresponding tissue.
For each GO term:

If the term is present in the corresponding enrichment result, the associated p-value is reported.
If the term is not present in that analysis, the value is recorded as NA.

This merged table facilitates direct comparison of GO enrichment signals between DASGs and DEGs.
